## 📖 О проекте

«Big Drop Edition» — это текстовое казино, в котором упор сделан на **ощущение большого заноса**. Механика настроена так, чтобы игрок часто что-то выигрывал (пары, тройные вишни), но при этом существовал редкий исход — **Big Drop** (💎💎💎, ×50) и **Mega Drop** (7️⃣7️⃣7️⃣, ×100), а также **Джекпот** (👑👑👑), забирающий весь накопленный банк.

Банк джекпота растёт на **1% с каждой ставки**, поэтому даже серия проигрышей увеличивает потенциальный дроп.
