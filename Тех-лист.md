Проект: «Console Casino — Big Drop Edition» 🎰
🎯 1. Цель
Создать консольное казино на Python, в котором игрок испытает азарт с ОГРОМНЫМИ шансами на БОЛЬШОЙ ДРОП. Программа должна давать ощущение настоящего казино: крутить слоты, делать ставки, ловить джекпоты и умножать виртуальный баланс. Главная идея — поток положительных эмоций: дроп должен случаться часто и быть крупным, но без «читерства» — всё честно через генератор случайных чисел.

Ключевая фишка: высокая частота выигрышей + редкий, но огромный джекпот (Big Drop), который переворачивает игру.

👥 2. Пользователи
Игроки-новички, которые хотят «пощупать» механику азартных игр без реальных денег

Начинающие разработчики, изучающие циклы, словари, random и обработку ввода

Интерфейс: консоль (текстовое меню, ASCII-слоты)

🎲 3. Входные данные
Команды меню: spin (крутить), bet (изменить ставку), balance (показать баланс), stats (статистика), quit (выход)

Ставка: целое число (строка → валидация → int)

Стартовый баланс: задаётся константой (например, 1000 кредитов)

📤 4. Выходные данные
При выигрыше: сумма выигрыша, обновлённый баланс, анимация/сообщение («💥 BIG DROP!», «🎉 Джекпот!»)

При проигрыше: «Не повезло, крути ещё!», обновлённый баланс

При ошибке: «Недостаточно средств», «Неверная ставка», «Игра окончена — баланс 0»

Статистика: число спинов, самый крупный выигрыш, текущий баланс

💾 5. Структура данных
Баланс: int

Ставка: int

Конфигурация символов: словарь {symbol: {"weight": шанс, "payout": множитель}}

Таблица выплат: словарь комбинаций → множитель

Статистика: словарь {"spins": 0, "biggest_win": 0, "big_drops": 0}
Корректно работает меню из ≥ 4 команд

Обрабатывает неверный ввод без падений (try/except + валидация)

За ≥ 20 спинов выпадает хотя бы 1 выигрыш и хотя бы 1 «крупный» (дроп/джекпот при достаточной серии)

Баланс корректно обновляется, не уходит в минус

Код опубликован на GitHub с историей ≥ 3 коммитов

В README.md есть инструкция по запуску, описание символов и таблица выплат
